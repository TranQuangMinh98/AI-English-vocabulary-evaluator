# English Conversation Practice

A guided conversation where a learner answers topic-based questions and receives vocabulary feedback.

## Language

**Conversation**:
One learner session that moves through Basic Introduction and then Hobbies.
_Avoid_: Evaluation session, chat

**Topic**:
A stage of the Conversation containing three related questions.
_Avoid_: Category, lesson

**Basic Introduction**:
The first Topic, covering the learner's name, origin, and occupation.
_Avoid_: Introduction, personal details

**Hobbies**:
The second Topic, covering the learner's favorite hobby, motivation, and frequency.
_Avoid_: Hobby, interests

**Question**:
A fixed prompt in a Topic that the current Learner Response is expected to address.
_Avoid_: AI prompt, task

**Learner Response**:
The learner's submitted answer to the current question.
_Avoid_: User prompt, message

**Topic-Aligned Response**:
A Learner Response that addresses the current Question closely enough to continue.
_Avoid_: Valid response, correct answer

**Unrelated Response**:
A Learner Response that does not address the current question or its Topic.
_Avoid_: Invalid response, wrong answer

**Evaluation**:
A CEFR assessment of complexity, accuracy, fluency, and clarity or pronunciation, produced for a Topic-Aligned Response by the existing evaluator.
_Avoid_: Conversation reply, score

**Input Mode**:
The learner's chosen response method for a Question: text entry or browser speech recognition.
_Avoid_: Evaluation mode, conversation mode

**Redirection**:
Guidance shown after an Unrelated Response to return the learner to the current question.
_Avoid_: Evaluation, correction

**Coach Reply**:
An AI-generated acknowledgment grounded in a Topic-Aligned Response, followed by the next fixed Question, Topic transition, or completion message.
_Avoid_: Evaluation, AI response

**Skipped Question**:
A question abandoned after two consecutive Unrelated Responses so the Conversation can continue.
_Avoid_: Failed question

**Inspire Response**:
A fixed exemplary answer for the current question that the learner may reuse or adapt.
_Avoid_: Perfect response, suggested answer
